# Data Dictionary

Source: IFPA IT Service Desk open-data documentation.

| Field | Type | Description |
|---|---|---|
| Ticket ID | Numeric | Ticket identification code |
| Category | Text | Ticket category |
| Title | Text | Ticket subject |
| Requester | Text | Requester name |
| Opened | Date | Ticket opening date |
| Closed | Date | Ticket closing date |

> Note: this table represents the official core data dictionary. The annual CSV files will be profiled separately because their schemas and formatting may differ across years.

## Privacy note

Although the source dataset is publicly released, analytical outputs should avoid unnecessarily exposing requester names. The project will focus on operational patterns rather than individual identification.
